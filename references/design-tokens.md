# 设计 token 与文字规范

## 配色（锁定，不接受任意 hex）

| token | 值 | 用途 |
|---|---|---|
| `--navy` | `#0F1B33` | 最深底色（pano 表头、深色卡） |
| `--navy-2` | `#14233D` | 正文主色 / 深蓝横带 / 表头底 |
| `--navy-soft` | `#34507F` | 次级正文、导言 |
| `--teal` | `#4874CB` | 主蓝：强调、推荐、编号、进度框 |
| `--teal-br` | `#7BA0E6` | 深底上的亮蓝（dark 页 accent） |
| `--paper` / `--paper-2` | `#FFFFFF` / `#EEF3FB` | 纸面 / 浅蓝底块 |
| `--line` / `--line-2` | `#D7E0EE` / `#EAF0F8` | 分隔线 / 斑马纹 |
| `--line-dk` | `rgba(255,255,255,.20)` | 深底 hairline |
| `--muted` / `--muted-dk` | `#566479` / `#B6C8E6` | 弱化文字（浅底/深底） |

高亮底一律用主蓝低透明度：`rgba(72,116,203,.09–.13)`，不引入新色。

## 字号阶（偏可读，投屏后排可辨）

| token | 值 | 用途 |
|---|---|---|
| `--type-mega` / `--type-big` | 200 / 120px | 大数字页 |
| `--type-divider` | 90px | 分节大标题（封面主题 96px 行内） |
| `--type-title` | 64px | 正文页标题 |
| `--type-subtitle` / `--type-lead` | 38 / 37px | 副标题 / 导言 |
| `--type-body` / `--type-small` / `--type-mini` | 36 / 35 / 34px | 正文 / 表格 / 网格说明 |
| `--type-foot` | 32px | 页脚（`.nav` 26px 行内） |

**下限纪律**：任何上屏文字不小于 26px（`.mck.ops` 27px 是密度类唯一豁免）。
装不下 = 删文案或换母版，不是缩字号。

## 间距

页边距 `--pad-x:108px`、`--pad-top:78px`、`--pad-bottom:62px`；标题下间隔
`--gap-title:28px`。整 deck 统一，勿按页改 token（个别页可行内微调 padding）。

## 字体

推荐阿里巴巴普惠体 3.0（免费商用授权，官网可下载；本仓不随附字体文件）。放入
assets/fonts/ 并取消模板 @font-face 注释后，两物理字重映射全字阶：Regular 承
300–500、Bold 承 600–900；未安装时回退系统黑体（苹方 / 微软雅黑），版式不受影响。
`--ff-serif` 与 `--ff-sans` 当前同指普惠体（保留两个 token 是给未来换衬线标题留位）。
习惯：标题/强调走 `--ff-serif` + 700，说明文字走 `.sans`。

## 中文排版纪律

- 弯引号 `“ ”`（嵌套外双内单 `‘ ’`）；中文冒号 `：`；中文括号 `（）`；
  ASCII 直引号只许出现在代码与 URL
- 破折号用单个 `—`（U+2014），勿用 `——`（普惠体会留缝）
- 数字与单位：金额"约 X 万元"带"约"留余量口径；表内金额 tabular-nums 右对齐
- 不可拆短词（系统名/机构名）包 `<span style="white-space:nowrap">` 或组件自带 nowrap
- 无装饰 emoji；状态指示可用 ✅/❌/⏳/⚪ 四枚

## 汇报文风速查（写文案时）

- 每页标题 = 判断句（"推荐政务云"），页内容 = 证据
- 副标题/导言 ≤ 25 字为宜，收在判断上
- 幻灯片 ≠ 报告搬运：一页只讲一件事，讲不完拆页
- 领导视角：每页开头点视角（对外/对内、哪条线）、分类互斥、术语全程统一不简写系统名
